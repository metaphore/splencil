# Changes

## 1.1.0

- Rotate and scale stencils around the cursor position at the start of the drag.
- Switch to the Paint tool on paste and activate a white Splencil brush, including when Unified Color is enabled.
- Center newly pasted stencils in the 3D viewport, including pastes with background removal.
- Show the Splencil logo on the brush thumbnail in the Asset Shelf.
- Bundle the brush icon in release ZIPs and use the add-on metadata version by default.
